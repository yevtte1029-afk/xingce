## Tips

- 题库可以按题目类型、错题、未做题等筛选
- 在同一设备中做题记录会被保存，筛选未做题即可。换设备则刷新记录
- 题库来源于网络资料。其中存在少部分有误解析，遇到这种情况无需过度深究
- 文字题做了高亮功能，资料分析有内置计算器。可根据不同的测评要求选择性使用
